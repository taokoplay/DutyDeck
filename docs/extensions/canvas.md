# 画布（Canvas）

画布用节点组织执行者、素材和产物，用连线记录关联、参考、依赖或派生关系。你可以在一张图中查看候选、正式版本和执行状态。

## 先选对工作台

| 任务 | 建议入口 |
| --- | --- |
| 制作可点击页面、页面状态与开发交接 | 交互设计 |
| 管理漫剧、影片、宣传片、图片、分镜和剪辑 | 影像创作 |
| 组织多种素材、执行者与产物之间的关系 | 画布 |

画布继续保留独立入口。普通对话、写代码或一次性文件交付不需要先创建画布；已有画布关联也不代表每个新任务都要在画布里执行。

## 能做什么

### 节点与关系

- 节点类型包括 Agent、图片、音频、视频、文档和 WebView。
- 连线明确区分关联（association）、参考（reference）、依赖（depends-on）和派生（derives），不能把所有连线都当成执行顺序。
- 可在图面上定位相关节点、整理布局，并在节点工作台查看详细内容。
- 音视频节点可承载媒体内容；能否生成取决于所配置的模型和已接入执行器，不由节点类型决定。

### Agent 与执行

- 普通项目 Agent 可使用已开放的画布能力，在授权项目和关联画布范围内管理内容。
- Canvas Agent 用于需要独立上下文或持续迭代的专业分支；单次媒体执行保留自己的任务记录。
- 支持运行 Agent、按支持的依赖关系执行工作流，以及查看、恢复或取消任务。上游变化不意味着自动启动下游生成。
- 布局和界面操作依赖当前可用的前台工作区；后台任务完成不等于用户界面已经展示结果。

### 候选与版本

- 新产物与正式采用版本分开保存，可预览、采用或放弃候选。
- 节点展示和后续输入使用对应的正式版本，保留任务、素材和版本之间的归属。
- 影像分镜的“空镜头唯一图片自动采用”属于影像模块规则，不应泛化成所有画布产物自动采用。

### 画布管理

- 按项目新建、切换、重命名、设为默认或归档画布。
- 节点删除保留可恢复记录；删除画布有独立确认和运行任务检查。
- 同一画布一次展开一个完整节点工作台，图面继续保留其它节点和关系。

## 典型使用流程

1. 在当前项目打开画布，明确本次要组织哪些素材或产物。
2. 手动或通过 Agent 创建节点，为需要传递内容的节点建立合适关系。
3. 配置并执行当前可用的能力，在任务和制作记录中查看结果。
4. 预览候选、确认采用，再继续下游任务或交付；需要页面原型或按集剪辑时使用对应专业工作台。

## 数据与权限

- 项目正式数据位于 `<项目根>/.proma/design/`，包含画布、素材与创作上下文；项目内 `.proma` 是保留的兼容目录。
- 可重建缓存位于业务数据根的 `design-cache/<projectId>/`，默认即 `~/.DutyDeck/design-cache/<projectId>/`；自定义数据根以设置为准。
- Agent 与画布的关联由主进程管理。打开标签、选中节点等界面状态不授予跨项目访问权限。
- 异步修改会复核版本、项目权限和任务状态；不能覆盖用户已更新的内容。
- 第三方 Skill 不会因此获得额外权限，也不能绕过模型执行、凭据或项目边界。

## 使用边界

- 媒体配置中的可用状态是执行依据。即梦图片使用本地 CLI 登录态；即梦视频执行器尚未接入。
- 不把“存在视频节点”理解为所有供应商的视频模型都可用。
- 跨画布上下文需要明确关联，不能隐式读取其他项目或画布。
- 本页截图用于说明节点布局，入口与能力以当前客户端为准。
