# 影像作品制作配置实施计划

用户已确认：在新增影像创作模块提供制作配置，复用全局 API 模型与 ComfyUI 服务/工作流，并与 Agent 制作及记录联动。

- 制作配置独立版本保存，旧作品缺省继承目录；显式空范围保持为空。默认按图片、视频、声音设置，凭据继续由全局配置管理。
- 能力目录来自已实现适配器和工作流实际输入/输出；配置可执行与服务在线验证分开表达。只公开真实消费的参数，超限参考在准备时拒绝。
- Agent 本轮任务冻结配置。媒体准备绑定任务并合并默认参数，执行前复核来源、归属与任务状态。多个作品任务须明确 jobId，禁止猜测。通用媒体工具保留原授权策略。
- 制作记录只读取主进程冻结媒体请求，不接受模型伪造参数、模型或引用素材。按运行身份有界、幂等更新。
- UI 复用现有 Dialog/Select/Button 与主题：默认方案、当前能力卡片、添加/参数弹窗、失效提示、显式保存及全局设置入口。
- 验证：配置持久化和并发、旧作品兼容、任务冻结与无效来源、API参考上限、Comfy工作流合同、真实工具接线；之后全仓类型检查和相关UI烟测。所有生成测试使用隔离fixture，不调用真实付费服务。

关联影响：配置不改变作品内容版本或已采用素材；原画布继续独立。配置页不扫描服务器或后台轮询；目录、配置和制作回执均限制数量与大小。
