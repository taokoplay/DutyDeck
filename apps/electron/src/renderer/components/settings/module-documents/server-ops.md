# 服务器运维

## 简介

在已经授权的资源和真实连接范围内检查服务器、服务日志和数据连接，辅助定位运维问题。

## 适用场景

- 查看已授权服务器的状态和关键指标。
- 检查服务日志、进程和连接情况。
- 根据真实连接状态整理故障线索和下一步操作。

## 使用前准备

- 当前消息明确选择「服务器运维」。
- 已配置并授权目标服务器、数据库或远程资源。
- 连接凭据和资源范围由宿主管理，不能仅靠文字描述补齐。

## 使用流程

1. 读取已授权资源清单和连接状态。
2. 执行范围内的只读检查并记录来源。
3. 整理异常、影响范围和可验证的处理建议。
4. 涉及写入、重启或高风险操作时单独请求确认。

## 能力范围

- 列出可用运维资源。
- 查看服务器概览、服务状态和日志。
- 基于真实连接结果输出诊断线索。

## 产物类型

- 运维检查任务
- 服务器或服务查询结果
- 带来源的诊断记录

## 权限与限制

- 选择模块不会扩大服务器、数据库或远程文件权限。
- 未连接或未授权的资源不会被猜测或模拟。
- 写入、删除、重启和变更配置需要现有审批流程。

## 常见使用示例

> 查看已授权的生产 API 服务状态和最近 100 行错误日志，只读检查并标出需要我确认的风险。

> 检查当前已授权资源的数据库连接情况，按真实返回结果整理可能的故障范围。
