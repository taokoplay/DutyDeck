# 接口工作台

## 简介

准备、调试和保存项目接口请求与测试流程，帮助把一次调用整理成可复用场景。

## 适用场景

- 从已有接口文档或请求样例准备调用。
- 调试请求参数、认证和响应结构。
- 把验证过的请求保存为可复用的测试场景。

## 使用前准备

- 当前消息明确选择「接口工作台」。
- 已选择项目；可复用已有请求，也可提供接口文档或请求样例建立新请求。
- 出网调用、写入场景和敏感数据处理均需当前授权。

## 使用流程

1. 读取项目内已有请求、变量和场景。
2. 生成精确的请求快照并检查风险。
3. 在获得授权后发送请求并记录响应。
4. 按用户确认保存或更新接口场景。

## 能力范围

- 读取和整理项目接口请求。
- 准备请求、检查参数和认证配置。
- 发送已授权请求并保存可复用场景。

## 产物类型

- 接口请求
- 请求运行记录
- 接口测试场景

## 权限与限制

- 不会重复发送可能产生副作用的请求。
- 没有精确请求快照和授权时只提供准备建议。
- 敏感凭据不会因为模块选择而暴露给模型或写入普通说明。

## 常见使用示例

> 读取项目里已有的登录接口请求，检查参数和认证配置，先生成一份待确认的请求快照。

> 用当前已授权请求验证订单查询接口，记录响应并在我确认后保存为测试场景。
