# 交互设计

## 简介

生成、还原和迭代可点击的 App/Web 原型，帮助验证页面结构、交互路径和视觉方向。

## 适用场景

- 从需求快速建立可点击的 App 或 Web 原型。
- 读取已有原型并针对页面或交互路径迭代。
- 在真实设备尺寸和页面边界内验证设计方案。

## 使用前准备

- 当前消息明确选择「交互设计」。
- 已选择项目；新建或修改已有原型需要项目文件权限。
- 明确目标平台、页面范围和需要验证的交互路径。

## 使用流程

1. 确认项目、原型和目标页面边界。
2. 读取已有页面、组件和交互上下文。
3. 提出或生成候选变更，保留页面级身份。
4. 检查候选差异并按当前授权采纳；采纳前校验版本，避免覆盖人工修改。

## 能力范围

- 读取原型、页面和可交互元素。
- 生成页面候选、交互路径和视觉调整建议。
- 在手机、桌面和浏览器视口中预览原型。

## 产物类型

- 交互原型
- 原型页面
- 交互候选和页面变更记录

## 权限与限制

- 生成候选与采纳是两个步骤；Agent 可按授权自动采纳，正式原型是否更新以采纳结果为准。
- 不会把整套页面隐藏在单个无法追踪的 HTML 中。
- 原型验证不能替代真实工程源码、可访问性和跨浏览器验收。

## 常见使用示例

> 为这个产品创建一个包含登录、注册和找回密码流程的 Web 原型，先给我可点击候选。

> 读取当前原型的首页，保持现有导航结构，优化首屏信息层级并给出可预览候选。
