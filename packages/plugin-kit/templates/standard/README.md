# 标准插件工程

这是一个包含自身模块、Skill 与提示的内容插件。编辑 `plugin.json` 和资源后，先校验，再在隔离的开发数据根试用。

```bash
bun run validate
bun run test
bun run pack
```

`pack` 默认产生未签名开发包。正式本地分发前创建作者密钥并使用 `pack --release --config-dir <作者配置目录>`；私钥不得放入插件工程或 Git。导入客户端时核对发布者指纹，安装后在消息底栏选中模块才能接入其内容。

所有 Skill 需声明所属模块，提示应写明用途、输入、输出和内容。设计约束是按需携带的包内资源；无关插件无需添加。保持版本和资源引用一致，测试/构建产物与凭据不会自动成为包载荷。

当前模板不注册可执行工具、独立界面或后台服务。支持矩阵以 SDK 校验结果和目标客户端版本为准。
