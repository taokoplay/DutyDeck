# DutyDeck v0.20.19

## Agent、知识库与工作区

- 接入 LibTV 官方媒体工作流，并完善媒体模型、MCP 超时与配置管理。
- 增强 Vault 分页读取、项目知识库与记忆工作流，降低大目录和长内容对会话的压力。
- 优化 Agent 会话完成通知，避免重复携带完整历史消息，由渲染层按需读取已持久化会话内容。

## 电脑控制与影像创作

- 新增电脑控制能力的权限、驱动安装、操作审批、截图和运行时服务边界。
- 完善视觉创作的多作品目标绑定、引用素材准备、交付检查和文本交付核验。
- 修正剪辑页同时显示多个视频预览的问题。

## 构建与运行隔离

- 为原生 helper 增加基于输入指纹的增量构建，减少重复编译并在工具链或输入变化时自动重建。
- Windows 与发布流程中的相关回归测试启用测试隔离，避免 mock 状态在测试文件之间泄漏。
- DutyDeck 正式版与开发版始终使用独立的 Electron userData 目录，不再因旧 Proma 目录存在或为空而共享 Chromium `SingletonLock`。
- 保留旧 Proma userData 与 Safe Storage 路径用于显式迁移和诊断，不将其作为 DutyDeck 的运行目录。

## 验证与已知限制

- 已通过 DutyDeck/Proma userData 隔离与应用身份相关回归测试：11 项测试、0 失败。
- 已通过全仓类型检查。
- 已通过主进程构建；构建仍会输出 `import.meta` 在 CJS 中不可用的既有警告。
- 完整跨平台发布构建和真实安装升级验证仍需在发布流水线及目标平台完成。
