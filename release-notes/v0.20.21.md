# DutyDeck v0.20.21

## 会话历史与滚动体验

- 会话历史支持直接向上滚动自动读取更早消息，向下滚动到真实底部自动读取较新消息，不再依赖弹窗式上一页/下一页交互。
- 长会话使用有界历史窗口、连续滚动锚点和巨型记录续扫，减少一次性读取、传输和挂载的消息数量。
- 侧栏会话列表继续使用虚拟列表，并新增局部滚动边界反馈；滚动状态封装在小组件内，减少整个侧栏的重复渲染。
- 文件变更面板支持本轮与更早变更分组，更早记录默认收起，降低长会话下的展示开销。

## Agent、媒体与工作区

- 增加自然语言媒体意图识别与 ComfyUI 工作流接入，支持媒体任务准备、参数校验和结果回传。
- 扩展上下文用量面板，并完善手动压缩的摘要降级与分块处理。
- 降低长会话流式更新与多会话状态残留，修复长会话打开时的历史顺序问题。
- 增加插件运行时、插件 SDK 与宿主材料构建链的独立能力边界，保留离线验收和授权隔离。

## 验证与边界

- 已通过会话连续滚动、历史窗口、侧栏渲染和滚动边界定向回归。
- 已通过 `bun run typecheck`。
- 本版本沿用跨平台发布流水线，在 GitHub Actions 中构建 macOS、Windows 和 Linux 产物；本机额外执行当前架构打包验证。
