# DutyDeck v0.20.2

## 独立品牌与兼容迁移

- 清理桌面帮助菜单、移动端页面和包描述中的用户可见 Proma 品牌残留。
- 移除 Proma Logo 设置入口、内置资源和下载 IPC；旧图标偏好统一回退到 DutyDeck 默认图标。
- `dutydeck` CLI 作为主入口，`proma` CLI 保留为兼容别名并显示一次弃用提示。
- renderer 与移动端 localStorage 改为 DutyDeck key 双读单写，旧值读取后复制到新 key。
- 默认业务数据根使用 `~/.DutyDeck/`；旧 `~/.proma/`、项目 `.proma/`、旧 Safe Storage、环境变量和协议值继续兼容。
- 新增从 Proma 迁移到 DutyDeck 的用户说明与自动化残留检查。

## 影响范围

旧版会话、工作区、渠道凭据和 Skills 不会因升级被删除。升级后首次读取旧配置可能发生一次原子归一化写入，运行时开销只出现在迁移或旧 key 命中时。
