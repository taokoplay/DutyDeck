# DutyDeck 0.20.1

## 修复

- 修复从 Proma 独立到 DutyDeck 后，最新版本模型配置中的 API Key 可能无法解密的问题。
- 启动迁移改为使用独立的旧身份读取凭据，再由 DutyDeck 身份重新加密；迁移失败或系统密钥库暂不可用时保留旧数据并允许下次重试。
- 修复迁移结果为零时被错误标记为完成的问题，并限制扫描范围只覆盖已知凭据文件。

## 兼容说明

- 旧 `~/.proma`、项目内 `.proma` 数据和旧凭据仍作为迁移输入保留，不会被自动删除。
- 发布、自动更新和下载入口继续使用 [taokoplay/DutyDeck](https://github.com/taokoplay/DutyDeck)。
