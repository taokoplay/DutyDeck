# DutyDeck v0.20.6

## Agent 模块与调用记录

- 专业模块可按当前消息选择接入，浏览器、终端等基础能力继续按需自动调用。
- 增加受管声明式模块插件的安装、刷新与卸载，完善模块命令队列和中断恢复核验。
- 调用记录按运行摘要、模块和工具执行分层展示，支持失败筛选与诊断展开。
- 精简输入区常驻状态；失败会话的侧栏提示在查看后清除，失败记录仍保留。

## 交互设计预览

- 设备菜单支持 12 种手机、平板和电脑模型，并新增浏览器 Web 预览。
- 显示当前型号与内容视口分辨率，内容按原型已有响应式样式适配；切换设备保留输入和脚本状态。
- 改善手机外壳、屏幕裁剪和默认大小，缩小上下留白，缩放控件移至下方，合并辅助说明。
- 完善页面版本对比与 Agent 采纳流程，保留冲突检查，避免覆盖用户修改。

## 图片与媒体

- 图片请求使用识图预览、精确去重和体积预算，保留原图与不同图片，改善请求体超限提示。
- 影像任务可按作品、镜头和资产引用准备视觉上下文，并在恢复时重新核验素材。
- 侧边文件预览支持图片、视频和音频，媒体从改动入口打开时也使用媒体预览，避免二进制乱码。
- 媒体沿用既有文件授权与缓存上限，音视频提供播放和进度控制；实际格式支持取决于内置播放器的解码能力。
