# DutyDeck v0.20.9

## 插件与 Agent 会话衔接

- 右侧工具栏按当前 Agent 会话动态展示已安装模块，点击模块即可接入当前会话并打开对应面板。
- 面板关闭只影响可见性；模块权限持续保留，展开工具菜单可明确执行“从本会话移除”。
- 已接入当前会话的模块图标使用绿色表示权限状态，面板打开状态继续使用选中背景，并提供文字与无障碍状态提示。
- 插件升级、禁用或包摘要变化时安全要求重新接入；运行中的会话不会在当前回合热扩权。
- 移除 Agent 输入区的模块选择入口，保留旧 `/module` 数据兼容，减少重复选择和调用中断。

## 专业模块与输入校验

- 交互设计项目列表合并历史原型并保留唯一入口，减少模块切换歧义。
- 允许归属当前项目的用户探索分支独立使用项目专业模块，并补充 Canvas、交互设计和影像创作的访问回归。
- 统一媒体生成受管资产输入合同，提前拒绝无法归属或缺少版本摘要的参考资源。
