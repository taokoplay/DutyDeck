# DutyDeck v0.20.4

## 分镜图片与剪辑

- 空镜头生成唯一图片后自动采用并显示；同镜头有多张图片或已有正式画面时保留选择。
- 修复采用一个镜头后，其他独立镜头的资源候选被误标为过期的问题。
- 接入剪辑候选的查看、采用和丢弃，支持片段属性设置及时间线编辑。
- 支持按视频轨顺序连续播放视频和静帧，到最后一个片段自动停止。
- 新增 MP4 成片导出入口，可按设置合成画面、音轨和字幕；需要本机已安装 FFmpeg。

## 会话与模型

- 修复错误回合无法回退或分叉的问题，并兼容能明确定位到原始消息的历史错误提示。
- 支持渠道模型级上下文窗口配置，改善第三方 OpenAI 兼容网关的窗口识别。
- 改善网络错误重试，并保留重试时的 Skill、MCP、媒体模型等引用参数。

## 验证边界

- 265 项相关测试、全仓类型检查、Electron 构建及隔离数据下的影像工作台界面回归通过。
- 剪辑导出已覆盖模拟编码器回归，尚未完成真实音视频端到端验收。
