# DutyDeck v0.20.16

## 影像 Agent 全链路

- Agent 现在可以完成作品创建、剧本、资产、镜头计划、媒体生成、候选审核与精确采纳、粗剪、时间线修改和导出请求，不再要求用户手工推进重复步骤。
- 锁定角色和资产继续保留保护边界。正式采用涉及锁定变更时，复用项目原生权限弹窗，展示候选、正式版本和字段前后值；授权仅对当前候选生效，不能永久允许或被完全自动模式绕过。
- 新增时间线和导出工具，Agent 可读取真实时间线、创建粗剪、提交并采用结构化剪辑候选，再请求成片导出和核对导出终态。
- 媒体任务改为 Host 托管等待。相同状态和重复进度不再反复推进 revision，模型不再承担逐 revision 轮询；成功、失败或取消后才续行处理产物。

## V3 插件运行时

- 插件中心支持 `.ddplugin` 拖放导入、格式识别、安装预览、版本历史、兼容性检查和签名信任。
- 新增项目产物能力与只读项目文件能力，产物按插件、工作区和产物身份隔离，并执行 revision/CAS 校验。
- 插件 Surface 新增主题合同、组件样式、错误恢复、只读状态和创建提示，改善深浅主题及特殊主题下的显示一致性。
- 源码开发版默认使用隔离的未签名插件运行目录，打包版继续强制生产签名边界。

## Agent 稳定性

- 修复 Agent utility 子进程无法及时退出时的 15 秒误报。优雅终止超时后会确认 PID 并升级为强制终止，清理异常不再覆盖已经完成的业务结果。
- 完善 Agent 完成门禁、运行代次和模块工具可用性检查，避免过期审批、旧运行或缺失工具被误报为成功。

## 验证

- 媒体任务与影像创作定向回归 894 项、3967 个断言通过。
- 插件运行时、SDK、Surface、项目产物与权限边界定向回归通过。
- Electron 类型检查、Renderer 构建和完整 Electron 构建通过。
- GitHub Actions 发布前会再次校验应用版本、标签和版本说明文件的一致性。
