# DutyDeck v0.20.7

## 插件管理与创建指南

- 插件管理新增「已安装 / 市场 / 创建插件」入口，统一查看六个内置专业模块与本地内容插件。
- 内置模块详情展示使用说明、提示词正文和 Skills 归属，改善详情排版与加载失败后的重试体验。
- 「创建插件」提供可离线阅读的制作说明，涵盖脚手架、资源编写、校验、签名打包和安装，命令支持复制。
- 支持安装、更新、启用、关闭和卸载签名 `.ddplugin` 内容包；包内模块、Skills、提示词及可选设计约束在当前消息明确选择后加载。
- 插件调用记录和恢复校验绑定包版本与内容摘要；安装管理保留运行状态检查、签名校验和资源访问边界。

当前市场为本地安装入口，尚未接入在线源。SDK 与 CLI 源码、脚手架及本地打包流程已随仓库提供，尚未发布到公共包注册表；本版不开放第三方动态工具、界面或运行时扩展。

## 媒体模型使用修复

- 直接选择媒体模型即可为当前消息装配共享媒体生成工具，无须额外勾选影像创作或画布模块。
- 完善选模型消息的排队与恢复，后续消息不会继承上一条消息的媒体能力；专业模块与生成审批仍沿用各自授权规则。
