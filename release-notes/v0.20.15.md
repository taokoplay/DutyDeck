# DutyDeck v0.20.15

## 交互设计画布与参考图

- 交互设计新增“原型预览 → 画布 → 参考图”三视图。画布直接读取正式页面和跳转关系，不建立第二套分组或流程事实。
- 页面节点按当前设备比例显示真实静态首帧，缩略图在隔离沙箱中渲染，不在画布中执行页面脚本。
- 新增版本化参考图：支持结构、视觉、文案用途，并关联到页面、状态或流程；图片正文继续存放在独立资产库。
- 参考图可以从 Finder 直接拖入，支持 PNG、JPG、GIF、WebP；拖入后自动登记为当前页面的视觉参考。
- 参考图卡片完整显示整张图片，点击后复用 DutyDeck 原生图片查看器，支持多图切换。
- Agent 新增固定版本参考图读取能力，可获取关联、用途、SHA-256、MIME 和字节数，再按需读取原图。

## 插件模块运行时

- 新增 V3 `module-runtime` 模块合同、宿主签名信任、不可变包展开、受控能力代理、Surface 与工具贡献机制。
- 内置模块与开发者模块继续共享稳定 Skill 引用和宿主授权边界。

## 项目知识库

- 知识库维护范围改由 Agent 自动接管，减少逐组确认和手工整理。
- 支持单篇大纲新增与正文追加，未修改的历史来源保持原样，降低无关版本变化对维护任务的阻断。

## 影像创作

- 完善整集结构化剧本、逐个节拍与镜头映射、画面/视频/声音独立输出和视频审核门禁。
- 增加视频工作流发现、分镜衔接、参考资产绑定与产物来源审计，避免静帧或占位符被误报为已交付影片。

## 发布构建

- Linux 构建显式安装项目锁定版本的 `node-gyp@12.4.0`，满足 `node-pty` 在没有 linux-x64 预构建时的源码编译要求。
- Linux 继续先准备 Node.js 22 和 Bun，并在依赖安装前验证工具可用性。

## 验证

- 交互设计、发布工作流与版本合同定向回归通过。
- 全仓类型检查、Renderer 构建和完整 Electron 构建通过。
- GitHub Actions 会在发布前复核版本、标签和说明文件一致性。
