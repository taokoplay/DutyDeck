# DutyDeck v0.20.23

## Skills 多作用域目录

- Skills 解析支持项目、当前工作区、用户全局和内置四层作用域，按项目 > 工作区 > 全局 > 内置去重，同名 Skill 只保留最高优先级版本。
- 新建工作区不再复制内置 Skill；内置 Skill 通过共享目录读取并保持只读，减少重复存储、启动升级扫描和版本漂移。
- 全局与项目 Skill 的启停写入对应设置文件，删除高优先级 Skill 后会重新解析并显示可用的低优先级版本。
- Skill 激活记录按 query 冻结的实际目录归因，项目、全局和内置 Skill 不会被误记为当前工作区 Skill；catalog 单次扫描同时复用加载目录和归因目录。
