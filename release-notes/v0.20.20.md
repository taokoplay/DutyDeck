# DutyDeck v0.20.20

## 会话历史与展示性能

- 长会话改用有界尾页读取与历史分页，支持较早/较新历史、返回最新消息和跨页搜索定位，减少首次展示需要读取、传输和挂载的历史内容。
- 将历史阅读窗口与实时输出分开，保留文本选区、分页滚动锚点和工具展开状态；搜索结果可展开嵌套子代理内容。
- 为超长记录提供分段详情和保留记录入口。展示窗口的限制不删除原始 JSONL，也不缩短模型恢复、编辑、导出所依赖的权威历史。
- 新增可重建的版本化历史索引、精确持久化确认和权威重试输入读取，防止迟到刷新、历史截断或新一轮运行导致消息顺序和归属错误。
- 会话上下文用量改用有界尾读与可信版本快照；不确定时保留未知状态，不以旧值或零替代。

## 计划审批与文件预览

- 计划模式仅允许在当前会话的计划目录内写入 Markdown 计划，提交审批时必须绑定计划文件。
- 审批前后校验文件边界、大小和内容版本；文件被修改、删除或替换为链接时拒绝旧审批，不切换到执行权限。
- 增加只读计划预览，嵌入会话使用独立预览对话框；审批快捷键仅在审批卡获得焦点时生效。
- 消息中的文件链接、行内路径和图片引用按所属会话及目录上下文解析，避免切换会话时误用全局当前会话。

## Markdown 表格编辑

- 支持通过右键菜单插入和删除行列，以及删除整张表格；列操作保留至少两列。
- 结构编辑先合并尚未提交的单元格草稿，保留目标单元格焦点，并防止提交期间的 blur 事件重复写入。
- 整表删除沿用编辑器撤销历史；只读预览不提供编辑操作。

## 验证与边界

- 独立发布源码快照通过相关功能与发布契约联合回归：35 个测试文件、418 项测试、0 失败，并通过类型检查和 Electron 构建。
- 使用临时数据目录完成真实 main/preload/renderer 的首次启动、再次启动和数据目录冲突恢复冒烟；既有配置原文保持不变。
- 已完成合成历史读取基准、隔离 Electron IPC 与真实消息组件的分层验证。这些结果不等同于完整会话收发的端到端性能或安装升级验收。
- 展示窗口有界不代表整个进程的内存恒定；未确认的实时消息缓冲仍会保留，复杂历史操作仍可能出现长任务。
- 本版本不调整摘要模型、压缩阈值或 Pi 原生压缩、停止与重试策略。跨平台构建由发布流水线校验，真实安装升级仍需在目标平台验证。
