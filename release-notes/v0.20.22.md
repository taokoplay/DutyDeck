# DutyDeck v0.20.22

## 长会话加载与连续滚动

- 会话历史 JSONL 批次读取改为异步文件读取，索引扩展不再连续阻塞 Electron 主进程事件循环。
- Renderer 按有界窗口分阶段准备历史页，分批绑定消息身份并主动让出事件循环，减少长会话打开和翻页时对输入、滚动的影响。
- 首次加载无缓存会话时显示带耗时的加载动画；向上自动读取历史期间保留当前内容并显示读取进度，不再依赖弹窗式上一页/下一页。
- 翻页提交采用稳定滚动锚点，等待新页真实挂载后再恢复视口位置，避免异步 transition 导致跳动。

## 验证

- 长会话相关定向测试：56 项通过，163 个断言通过。
- Renderer 生产构建：`bun run --cwd apps/electron build:renderer` 通过。
- 全仓测试仍存在与本轮无关的 Server Ops、原生 helper、网络/TLS、文件 watcher 和数据库服务环境失败；全仓 typecheck 仍存在既有类型问题，未归因于本轮改动。
