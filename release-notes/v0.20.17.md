# DutyDeck v0.20.17

## 项目数据目录

- 新项目使用 `.dutydeck` 保存设计、知识库、交互设计和影像数据；旧项目在设置页显式迁移前继续使用原 `.proma` 目录。
- 新增迁移状态、活动任务检查、冲突保护与中断恢复，保留未知旧文件和历史附件兼容读取。
- 历史语义搜索使用当前活动数据根，兼容默认目录和自定义目录。

## Agent 稳定性与协作

- Pi runtime 升级至 1.4.0，保留中文 token 估算、usage 未知值、空响应拒绝和有界重试补丁。
- 网络变化后仅对停滞的模型流触发恢复，交由 Pi 原生重试；不重新发送用户消息或重放已执行工具。新增内存脱敏网络诊断与导出。
- 协作结果支持摘要、预览、完整正文分页及字符预算，减少长回执占用上下文。
- 主界面连续崩溃的自动恢复预算需持续健康一分钟后才重置，避免反复加载与崩溃。

## 影像审查与剪辑

- 声音候选增加独立审核门禁，关键画面、动作、连续性或声音缺陷阻止正式采用；证据缺失保持待审，并限制纠偏续行次数。
- 剪辑支持替换正式片段来源、补入独立音轨，并校验源媒体身份、版本、hash 和真实时长。
- 新增待审候选的原生声画预览，冻结作品与时间线版本；预览不修改正式时间线，也不放宽正式采用条件。
- 完善首尾帧抽样和视频流边界判断，区分技术解码、视觉抽样与实际听验；修正小米 TTS 的语气指令与朗读台词传递。

## 验证与已知限制

- 37 个改动相关测试文件逐文件隔离运行，521 项测试、2643 条断言通过；全仓类型检查通过，Electron 构建各阶段通过。
- 项目目录迁移已完成隔离场景验证，Windows 迁移仍待实机验证。
- 候选预览和技术检查不代表影片内容验收，实际听验与连续性审查仍须完成。
- 开发版在完整构建与 Dev 共用 `dist` 时可能因连续热重载误入 `ERR_ABORTED` 错误页，该开发流程问题已定位，尚未修复。
